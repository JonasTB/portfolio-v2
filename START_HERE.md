# Portfolio — Claude Code Starter Kit

Este pacote contém as instruções para o Claude Code planejar e implementar um novo portfólio pessoal a partir do zero ou evoluindo um repositório existente.

## Como usar

1. Extraia este conteúdo na raiz do repositório do portfólio.
2. Abra o Claude Code nessa mesma raiz.
3. Peça ao Claude para ler `CLAUDE.md` e todos os documentos referenciados nele.
4. Não peça para implementar tudo de uma vez.
5. Comece com:

```text
Execute a ETAPA 01.
```

6. Revise o resultado de cada etapa antes de avançar.
7. Para continuar:

```text
Execute a ETAPA 02.
```

...e assim sucessivamente.

## Referências visuais incluídas

- `docs/references/portfolio-old-light.png`

As imagens são referência de identidade do portfólio antigo, não um layout para ser copiado.

## Arquivos principais

- `CLAUDE.md`: regras permanentes para o Claude Code.
- `docs/PRODUCT_BRIEF.md`: visão do produto, conteúdo e experiência.
- `docs/TECHNICAL_ARCHITECTURE.md`: stack, arquitetura, integrações e padrões técnicos.
- `docs/EXECUTION_PLAN.md`: plano em etapas 01–19.
- `docs/VISUAL_DIRECTION.md`: direção visual e como interpretar o portfólio antigo.
- `prompts/COMMANDS.md`: comandos prontos para conduzir cada etapa.

## Importante

O Claude deve trabalhar incrementalmente, executar validações ao final de cada etapa e nunca avançar para a próxima etapa sem autorização explícita.
