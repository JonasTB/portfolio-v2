# @portfolio/web

Frontend do portfólio — React 19, TypeScript, Vite, Tailwind CSS v4, React Router, TanStack Query.

Ver o [README na raiz do monorepo](../../README.md) para instruções de setup, scripts e documentação completa.

## Scripts locais

```bash
pnpm dev          # vite dev server (localhost:5173)
pnpm build        # tsc -b && vite build
pnpm test         # vitest run
pnpm lint
pnpm typecheck
```
